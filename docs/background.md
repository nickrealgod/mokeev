# Backgrounds

The initial background is assets/Background.jpg, shown without overlays. It shares the exact camera transform with letters and reflection: all three retain fixed relative positions and scale throughout the introduction. Its final placement uses proportional centered cover. Seven procedural backgrounds follow. No cursor reveal.

1. Gradient #F7FAFE → #FFF8ED .
2. Gradient #C0C0C4 → #BEC1C5, cached 2% uniform color noise.
3. #E4E7EB.
4. #FFFFFF.
5. #FBF8FF.
6. Gradient #D0DBE6 → #E7EAF1 → #E4E8EF.
7. #BEC1C5.

Manual and automatic transitions use cubic ease-out over 250 ms. The first automatic change is after 20 seconds, then every 15 seconds until the first manual change.
