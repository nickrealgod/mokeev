# Публикация на Vercel

Готовый сайт находится в `dist`. Здесь нет сервера приложения, зависимостей, ключей, внешних шрифтов или внешней загрузки картинок. PDF и SVG входят в комплект.

## Через GitHub и Vercel
1. Распакуйте архив и загрузите его содержимое в репозиторий GitHub.
2. В Vercel выберите Add New → Project и импортируйте репозиторий.
3. Root Directory — папка с `vercel.json`. Framework Preset — Other. Output Directory — `dist`. Build Command и Install Command — пустые. Эти параметры уже записаны в `vercel.json`.
4. Нажмите Deploy. Vercel выдаст HTTPS-адрес сайта.

Либо в распакованной папке выполните `npx vercel` и следуйте подсказкам Vercel.

Не загружайте исходный PSD и checkpoint: для публикации они не нужны. Сайт ещё не опубликован.

## Проверка после публикации
Откройте полученный URL на телефоне и компьютере: вступление, тап/наведение, направленную волну по прокрутке/свайпам, четыре фона по тапу на свободную область, скачивание PDF и три внешние ссылки. На устройствах с включённым «Уменьшением движения» вступление пропускается.

Используются стандартные Canvas 2D Color/Overlay, Pointer Events, WebP и локальные SVG. Проверена компоновка в браузере на мобильной ширине; физические iPhone/Android и все движки браузеров отдельно не тестировались. При очень больших экранах плотность canvas ограничена бюджетом 16 мегапикселей для памяти мобильных устройств; исходная белая € остаётся 3241 × 3172.

Документация: https://vercel.com/docs/builds/configure-a-build и https://vercel.com/docs/project-configuration/vercel-json

## Обновление
Замените файлы в том же GitHub-репозитории и сохраните изменения в production-ветке (обычно main). Vercel автоматически обновит существующий проект и его адрес. Новый проект создавать не нужно.
