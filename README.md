# Mokeev — Designer

Статический сайт, подготовленный для Vercel. Файлы сайта, изображения, логотипы и PDF находятся в `dist`.

## Текущая версия
- Нижний край первых шести белых букв — 50% высоты окна. Отражение — 9% сверху, исчезает у нижнего края.
- Четыре ссылки в углах: LinkedIn сверху слева, PDF сверху справа, Behance снизу слева, Telegram снизу справа. Отступы 5vw. Без стрелок; цвет #616367 во всех состояниях. Белые заливки PDF и Telegram прозрачные.
- Клик или тап по свободному фону переключает четыре фона по кругу. Буквы при этом не меняются.
- Наведение или тап по букве меняет её индивидуальный стиль.
- Прокрутка вниз и свайп влево/вверх меняют общий набор справа налево; обратные жесты — слева направо. Задержка между буквами 25 мс, переход каждой 100 мс ease-out. Каждая буква увеличивается на 3% за 100 мс и возвращается за 100 мс. Повторные жесты во время волны игнорируются, инерция прокрутки не запускает вторую волну.
- Color и Iridescent используют программные градиенты; в общем наборе две буквы без градиента, соседние градиенты различаются.
- Сохранены вступление, оригинальная белая €, движение букв и синхронное отражение.
